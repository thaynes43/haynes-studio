# After-Hours Return

Version 1 · Doll short

explains the return policy at a mint-green miniature counter. It sounds like
an ordinary parcel return. The return turns out to be a tiny envelope going
into an orange locker with a slot just big enough for the envelope itself.

Revise only `locker` as a silent whole-frame insert in the orange parcel-locker
alcove. Use the second set's pinned asset as the photo input so the insert reads
as a cut to a distinct place. Keep the mint-green counter as the story set.
Leave the person-edited `counter` board and the unstamped `ticket` board exactly
as supplied, in their original positions. Keep all three board positions.
